# Sigma | Personal Portfolio Website

A single-page, fully responsive personal portfolio built with plain HTML, CSS and vanilla JavaScript. No frameworks, no page builders.

**Live site:** https://YOUR-SITE.netlify.app
**Project:** The Sky Gen, Web Development, Project 01 (Beginner)

## Features

- Sticky navigation bar with smooth-scroll links and active-section highlight
- Hero section with name, tagline, illustration and one call-to-action
- About section with an 80-120 word bio and a downloadable CV
- Skills section with 8 skills, icons and animated progress bars
- Projects section with a responsive grid of 6 project cards
- Contact form with JavaScript validation, plus email and social links
- Footer with copyright line and social icons
- Dark-mode switch (remembers your choice), mobile menu toggle and scroll-to-top button
- Hover effects on buttons, tiles, skill cards, project cards and social icons
- Responsive at 360px, 768px and 1440px with no horizontal scrolling
- Keyboard-friendly: skip link, visible focus states, reduced-motion support

## Tech stack

- HTML5 (semantic elements)
- CSS3 (custom properties, Flexbox, Grid, media queries)
- JavaScript ES6 (no libraries)
- Google Fonts: Bricolage Grotesque and IBM Plex Sans
- Font Awesome 6 (icons, via CDN)
- Git and GitHub, deployed on Netlify

## Setup

1. Clone the repo: `git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git`
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

No build step or dependencies are needed.

## Deployment

Deployed on Netlify by dragging the project folder into the Netlify dashboard (or by connecting the GitHub repo). The site is static, so no build command is required.
