About me

I'm Ahmed, a front-end web developer who enjoys turning rough ideas into clean, fast and friendly websites. I started with a single HTML file and never stopped building: I now work comfortably with semantic HTML, modern CSS layouts and vanilla JavaScript.

I care about details like spacing, readable type and how a page feels on a small phone screen. I'm currently learning through The Sky Gen web development program, where every project pushes me to write cleaner code and ship real work. When I'm not coding, I sketch layouts, read about design, and look for the next problem worth solving on the web.
